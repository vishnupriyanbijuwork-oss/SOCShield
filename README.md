# SOCShield

## Project Overview

SOCShield is a collaborative cybersecurity project focused
on network monitoring, security detection, incident
investigation and reporting.

## Team Roles

- Member 1: Network Monitoring
- Member 2: Detection Engineering
- Member 3: Incident Investigation

## Day 1 Scope

- GitHub repository setup.
- Project folder organization.
- Documentation of three detection scenarios.
- Initial failed-login detection design.

## Security Disclaimer

All testing is performed only on systems and networks
owned by the team or for which the team has explicit
authorization.
